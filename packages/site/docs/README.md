## 어떤 강의인가요?

**css-matrix와 별개의 독립 강의**입니다. DOM/CSS로 에디터 뼈대를 만든 뒤, SVG path·stroke·fill 수학을 깊게 다룹니다.

## 시리즈 위치

```txt
css-matrix           → DOM/CSS/SVG overlay, Figma to CSS
svg-matrix (here)    → SVG rendering & path geometry
webgl-webgpu-matrix  → GPU renderer
```
